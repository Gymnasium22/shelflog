# Stage 8 — QR codes

## Done

- Stable `qr_token` on items, boxes, locations, documents (from earlier migrations)
- RPC `resolve_qr_token` — membership-aware resolve
- Deep link **`/q/{token}`** → login if needed → entity card
- `QrCodeCard` on entity pages (SVG via `qrcode.react`)
- Print sheet `/app/qr/print`
- Scanner `/app/scan` (`html5-qrcode` + manual token/link)
- Login preserves `?next=/q/...` after password / magic link

## Flow

1. Open item/box/location/document  
2. See QR → Print / copy link  
3. Scan with phone camera or **Скан** in app  
4. Opens `/q/token` → passport card  

## Free stack

- `qrcode.react` — generate  
- `html5-qrcode` — scan  
- No paid QR SaaS  

## Config

`NEXT_PUBLIC_APP_URL` must match real origin (local: `http://localhost:3000`) so printed QR links open the right host.
